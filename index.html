Fundamentos da Web

Página Estática

Uma página estática é aquela cujo conteúdo (código HTML, CSS e imagens) é fixo e entregue ao navegador exatamente como está armazenado no servidor. Ela não muda de acordo com o usuário ou o horário de acesso.

Exemplo real: O site de uma padaria local que exibe apenas o endereço, horário de funcionamento e o telefone de contato.

Página Dinâmica

Uma página dinâmica tem seu conteúdo construído em tempo real no momento em que o usuário faz a requisição. Ela frequentemente consulta bancos de dados e adapta o que é exibido com base nas interações do usuário, preferências ou status de login.

Exemplo real: O feed do Instagram, onde o conteúdo exibido muda constantemente e é exclusivo para cada usuário logado.

Fluxo Básico de uma Requisição Web

  1. Navegador (Cliente): O usuário digita uma URL e o navegador inicia a solicitação, enviando uma requisição HTTP.
  2. Rede/Internet: A requisição viaja pela internet até encontrar o endereço (IP) onde o site está hospedado.
  3. Servidor: O servidor recebe a requisição, processa as informações (podendo consultar um banco de dados no caso de páginas dinâmicas) e monta o pacote final.
  4. Resposta: O servidor envia uma resposta HTTP (contendo o código HTML, CSS e JavaScript) de volta.
  5. Navegador (Renderização): O navegador recebe a resposta, lê o código e renderiza a interface visual na tela para o usuário.
